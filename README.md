# PDF Editor

Edit any PDF in your browser. Files never leave your device — no upload,
no signup, no watermark on core editing.

See [MASTER_PLAN.md](MASTER_PLAN.md) for the full plan: competitor audit
(Sejda, PDF24, iLovePDF, Smallpdf, Stirling PDF), architecture
(pdf.js + pdf-lib, 100% client-side), and phases.

**Status:** Phase 1 (MVP website) in build — see MASTER_PLAN.md §4.
